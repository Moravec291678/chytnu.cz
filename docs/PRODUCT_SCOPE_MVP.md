# Produktový rozsah MVP

## Součást MVP

- soukromý osobní deník Catch a Trip;
- lokální CRUD a fotografie použitelné bez přihlášení;
- hledání, filtry, historie a pravdivé statistiky;
- export a bezpečná obnova;
- soukromý e-mailový účet, dobrovolné propojení ownerless dat a synchronizace mezi zařízeními;
- konflikty bez tichého přepsání, trvalá fronta a viditelné chyby;
- počasí a aktivita ryb jako dobrovolný orientační odhad;
- PWA shell jako webový základ pro beta ověření.

## Mimo první MVP

- feed, komentáře, likes, přátelé, Crew, chat a veřejné profily;
- XP, levely, achievementy, questy a jiná složitá gamifikace;
- veřejné mapy, heatmapy a sdílení přesných GPS;
- AI, marketplace, předplatné a placené funkce;
- Google login, dokud e-mail/heslo pokrývá první soukromou verzi.

Osobní mapa nebyla přidána: současný model ukládá GPS jako neověřený text a nemá spolehlivé souřadnice pro pravdivé piny. Přidání mapy před validovaným souřadnicovým modelem by vytvářelo zavádějící funkci.

## Kritérium vydání

Lokální web/PWA beta může začít až po fyzickém offline testu. Veřejná účtová verze navíc vyžaduje produkční cloud, právní dokumenty, obnovu záloh, cenový dohled a bezpečnostní kontrolu produkčních pravidel.
